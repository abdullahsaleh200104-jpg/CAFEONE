## 1) رفع التطبيق على GitHub (من الهاتف)
1. ادخل github.com وسجّل دخولك، ثم **New repository**، اسمه `cafe-one`، اجعله **Public**، ثم **Create**.
2. اضغط **Add file ← Upload files**، وارفع هذه الملفات الخمسة معاً:
   `index.html` · `sw.js` · `manifest.webmanifest` · `icon-192.png` · `icon-512.png`
   ثم **Commit changes**. (إذا لم يظهر خيار الرفع افتح الصفحة بوضع «موقع سطح المكتب».)
3. من **Settings ← Pages**: اختر **Deploy from a branch** ثم الفرع `main` والمجلد `/ (root)` ثم **Save**.
4. بعد دقيقة أو دقيقتين يظهر رابط التطبيق: `https://اسم-حسابك.github.io/cafe-one/`
5. افتح الرابط ومن قائمة المتصفح اختر **إضافة إلى الشاشة الرئيسية**. بعدها يعمل بدون إنترنت.

بياناتك (المنتجات والمبيعات) لا تُرفع إلى GitHub أبداً. هي على أجهزتك وفي جدول Google الخاص بك فقط.

## 2) ربط أكثر من جوال (خطوتان، ثم دعوة بضغطة)
كل الخطوات داخل التطبيق: **المزيد ← ربط الأجهزة**.
1. على جهاز المدير: اضغط **نسخ كود الجدول**، ثم افتح sheets.google.com وأنشئ جدولاً جديداً، ومن **الإضافات ← Apps Script** الصق الكود كما هو واحفظ.
   اضغط **Deploy ← New deployment ← Web app**، **Who has access: Anyone**، ثم **Deploy** ووافق على الصلاحيات وانسخ الرابط.
2. الصق الرابط في التطبيق واضغط **اختبار وتفعيل**.
3. لكل جوال جديد: اضغط **دعوة جهاز جديد** ← **إرسال عبر واتساب**. عندما يفتح الجوال الجديد الرابط يرتبط تلقائياً ويجلب المنتجات والأسعار والموظفين والطلبات.

يتزامن: الطلبات والطاولات والصندوق والمصروفات والمنتجات والموظفون وتوفر المنتجات.
المخزون والمشتريات والوصفات تُدار من جهاز المدير (الرئيسي)، ويُخصم المخزون عنده تلقائياً من كل المبيعات.
عند انقطاع الإنترنت تُحفظ التغييرات وتُرسل عند عودة الاتصال.

### بديل: الربط عبر Firebase (لحظي وأسرع)
1. افتح console.firebase.google.com وأنشئ مشروعاً جديداً.
2. من **Build ← Realtime Database ← Create Database**، اختر المكان و**Locked mode**.
3. من تبويب **Rules** اضغط «نسخ القواعد» داخل التطبيق (**المزيد ← ربط الأجهزة**)، والصقها مكان الموجود ثم **Publish**.
4. انسخ رابط قاعدة البيانات من أعلى الصفحة، والصقه في التطبيق واضغط **اختبار وتفعيل Firebase**.
5. دعوة الجوالات بنفس الطريقة: **دعوة جهاز جديد ← واتساب**.
الفرق: Firebase يزامن لحظياً بدل التحديث كل 4 ثوانٍ، لكن ملف Excel على Google Sheets التلقائي يحتاج الربط عبر Google Sheets.

## 3) النسخ الاحتياطي وExcel (من الإعدادات)
- **حفظ نسخة كاملة**: ملف واحد فيه كل شيء، للاسترجاع من «استرجاع من ملف».
- **تصدير كل البيانات (Excel)**: ملف Excel بـ13 ورقة (المنتجات، المبيعات، بنود المبيعات، المصروفات، المخزون، المشتريات، الورديات، الموردون، الهدر، الجرد، الموظفون، الوصفات، حركة المخزون).
- **نسخ تلقائية يومية**: آخر 3 أيام على الجهاز نفسه.
- **مع الربط**: يتحدث ملف Excel على Google Sheets تلقائياً كل نصف ساعة وعند إغلاق الوردية. أوراقه تبدأ بكلمة `DB`، ويفتح من «فتح الملف».

## 4) فحص بعد التركيب
1. الإعدادات: الاسم وسعر الصرف وعدد الطاولات.
2. أضف منتجاً، افتح وردية، وأجرِ عملية بيع ودفع.
3. جرّب طلب طاولة ← حفظ الطلب ← دفع الحساب من الطاولات، ثم تقسيم الحساب.
4. أغلق الوردية وتأكد من الفرق، وصدّر Excel، واحفظ نسخة كاملة.
5. بعد الربط: افتح التطبيق على جوال ثانٍ وتأكد أن الطلب ظهر عليه.

## 5) التحديث لاحقاً
استبدل ملف `index.html` في المستودع بالنسخة الجديدة (Add file ← Upload files). البيانات على الأجهزة لا تتأثر.
